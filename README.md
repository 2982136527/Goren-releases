# Goren

给飞牛影视（fnOS 的影视库）用的桌面播放端。下载解压就能用，不用安装环境、不用配置。

它直接读你 NAS 上已经建好的那些库 —— 电影、剧集、B 站、影音库，刮好的海报、简介、演员、
季和集都在。它**不会动你的媒体库**：不下载、不改名、不删文件、也不会往库里塞东西。
唯一会写回 NAS 的是观看进度（这样你换台设备也能从老地方接着看）。

## 你需要有什么

- 一台装了 fnOS 的飞牛 NAS，并且开了「影视」App
- 一个影视 App 的账号（就是你在飞牛上看片用的那个账号密码）
- 想在家里以外也能用的话，开通飞牛 ID

## 下载

去右侧的 **Releases**，最新一版下面有两个文件：

| 文件 | 给谁用 | 怎么用 |
|---|---|---|
| `Goren-1.0.5-macos-universal.dmg` | Mac（Intel 与 Apple Silicon 通用包） | 打开后把 Goren 拖进「应用程序」 |
| `Goren-1.0.4-windows-x64.zip` | Windows 10 / 11（64 位） | 解压到任意文件夹，双击里面的 `Goren.exe` |

### Mac 第一次打开

如果提示"无法打开，来自身份不明的开发者"：**对着图标按右键 →「打开」→ 再点一次「打开」**，
只有一次需要这么做。

右键也打不开的话，终端里跑一次（把 app 上的隔离标记去掉）：

```bash
xattr -dr com.apple.quarantine /Applications/Goren.app
```

第一次连局域网里的 NAS，macOS 会问「Goren 想查找并连接到本地网络中的设备」，点**允许**就行；
万一误点了拒绝，在「系统设置 → 隐私与安全性 → 本地网络」里把 Goren 打开。

### Windows 第一次打开

下载后**整个文件夹一起解压**，别只把 `Goren.exe` 单独拎出来（旁边的文件是它要用的）。
如果弹蓝色"已保护你的电脑"，点「更多信息」→「仍要运行」。

升级版本后如果图标还是旧的样子，那是 Windows 缓存了图标，不是包的问题 ——
解压到一个新文件夹，或者注销一次再看。

## 第一次登录

一个地址框，三种地址都能填，它自己认：

| 你填 | 什么时候用 |
|---|---|
| `192.168.1.10` | 在家，用局域网 IP（默认端口 5666） |
| `192.168.1.10:8443` | 你的影视服务不在默认端口上 |
| `你的飞牛ID` | 出门也想看，或者不想记 IP |
| `nas.你的域名.com` | 自己反代过、有域名的 |

**填飞牛 ID 或域名就够了，不用来回改地址。** 人在家里时它会先试局域网，能连上就直接走本地
（画面更稳、不占外网带宽）；出门连不上局域网，自动回到远程。想管这个行为的话在
「设置 → 自动选路」里，可以关掉，也可以手动填一个局域网地址让它去试。

## 能做什么

- **浏览**：首页推荐、按库浏览、搜索、按分类/年代/地区/排序筛选，侧边栏直接列你的所有库
- **详情**：海报墙、简介、演员、季和集、类似影片
- **播放**：直接取 NAS 的原始文件播放，拖动进度、切音轨、选下一集
- **字幕**：片子里带的字幕轨可以切、可以关；没有字幕的时候能在「字幕」菜单里直接搜在线字幕，
  点一条就下载挂上，看的时候随时删掉
- **接着看**：进度记在你的 NAS 上，换设备、重开都是同一个位置；看过的片子本机有标记
- **跳过片头**：设一个秒数，进剧集自动跳
- **倍速**：可记住上次的倍速
- **首页内容范围**：只让某几个库出现在首页，别的库仍然能进
- **海报墙布局**：竖幅海报 / 横幅海报随你切，每个库、每个分类各记各的，重开应用也记得住
- **界面**：深色、海报圆角可调

## 你的数据

- 服务器地址和账号密码**只存在你自己这台电脑上**（本机加密存储），不会上传到任何第三方
- 退出登录会把存在本机的这些清掉
- 播放时程序只和你的 NAS 通信，中间没有任何我们的服务器

## 常见问题

**连不上 / 转圈很久才进去** —— 先确认这台电脑能访问 NAS（同一个局域网，或者飞牛 ID 已开通）。
家里用远程地址会慢，改成局域网 IP 或让自动选路去走本地。

**提示"服务器响应超时"** —— 库很大时，第一次翻到某个分类会慢。设置里「请求超时」默认 30 秒，
可以调大。

**海报加载慢** —— 封面是从 NAS 现取的，第一次会慢，之后这台电脑上有缓存。

**首页没有某个库** —— 看是不是被「首页内容范围」挡掉了，那个开关只影响首页，不影响侧边栏进库。

**Windows 打开就闪退 / 提示缺文件** —— 多半是只拷了 `Goren.exe`，把整个解压出来的文件夹一起用。
